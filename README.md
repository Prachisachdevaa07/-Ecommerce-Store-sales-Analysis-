# Ecommerce Sales Data Analysis Using Excel

This project marks the beginning of my analytics journey. As I developed an interest in data, I started learning Microsoft Excel and applied my knowledge by building this small project. I completed it by following a YouTube tutorial to understand the fundamentals of data analysis and dashboard creation.

In this project, I analyzed an e-commerce sales dataset using Excel features such as Pivot Tables, Pivot Charts, slicers, filtering, sorting, and data visualization. The project helped me understand how to organize raw data, identify sales trends, and create an interactive dashboard for business insights.

### Key Learnings

* Data cleaning and preparation in Excel
* Creating Pivot Tables and Pivot Charts
* Building interactive dashboards using slicers
* Analyzing sales performance and customer trends
* Presenting data in a clear and visually appealing format

**Tools Used:** Microsoft Excel
